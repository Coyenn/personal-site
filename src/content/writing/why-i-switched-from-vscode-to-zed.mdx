## Backstory

My first ever line of code was actually written in Roblox Studio, an IDE used to create games on the Roblox platform. At the time, it lacked many basic features considered standard in modern editors. So I quickly moved onto more capable editors such as JetBrains' PHPStorm and WebStorm.

## Visual Studio Code, the best of both worlds?

I don't like slow, bloated software. When I'm writing code, I want to work quickly and efficiently. Five minutes of indexing and loading is, at least for me, unacceptable.

This is where Visual Studio Code comes in. It's fast, lightweight, open source, and free. There's a huge community creating extensions for it and it's available on all major platforms. For me, it ticks all the right boxes.

I feel like it's the perfect balance between a full-blown IDE and a simple text editor.

## The switch to Zed

As of a couple of weeks ago, I had been a happy user of VSCode. But recently I started looking for something new, something that was even faster, more lightweight, and powerful.

That's when I learned about Zed. Written entirely in Rust using a custom UI framework, it makes a strong case for speed.

Zed was still in beta at the time, with missing functionality, language support, and macOS-only availability. Windows and Linux support were planned but had no ETA.

## Why am I using it then?

To put it simply, Zed has everything I need for my day-to-day work. It supports the languages I regularly use, works seamlessly with GitHub Copilot, and most importantly, has Vim emulation.

## Would I recommend Zed?

If you're on macOS and looking for a fast, lightweight editor, then yes, absolutely. Zed is available for free, so I recommend giving it a try, especially if you use Rust or TypeScript daily.

If a language or feature you need is missing, you can open an issue on Zed's GitHub or upvote an existing one to help developers prioritize.
