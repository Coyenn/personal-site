# tim-dot-cv

Minimal CV site built with Next.js App Router, Tailwind CSS v4, shadcn/ui,
Oxlint, and Oxfmt.

## Commands

```bash
bun run dev
bun run lint
bun run format
bun run typecheck
bun run build
```

## Reference tokens

- `background`: `#11110F`
- `primary`: `#2E8EFF`
- `text`: `#B8B4A9`
- `secondary`: `#4C4944`

The font is Akkurat Mono.
